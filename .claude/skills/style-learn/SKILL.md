# 말투 학습

1. `20-posts/published/`에서 최근 발행본 10편을 읽는다. 10편 미만이면 `style-guide.md`의 예시 글과 함께 쓴다.
2. 뽑을 것: 평균 문장 길이, 자주 쓰는 어미, 자주 쓰는 표현·접속어, 글 구조 패턴(도입 방식, 소제목 스타일, 마무리 방식), 쓰지 않는 표현.
3. 초안 대비 발행본에서 반복적으로 바뀐 패턴이 보이면(예: 초안의 "~합니다"가 발행본에서 "~다"로) 규칙으로 추가한다.
4. `style-guide.md`의 "자동 추출 결과" 섹션만 갱신한다. "문체 규칙"은 사용자가 고친 내용을 지우지 않고, 새 규칙은 아래에 추가만 한다.
5. 갱신 날짜를 맨 위에 적는다.
