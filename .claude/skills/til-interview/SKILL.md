# TIL 인터뷰 (질문형)

목표: 사용자가 1분 안에 대답만 하면 되게 한다. 답은 저녁 답변 작업이 단다.

1. 마지막 inbox 메모 날짜를 확인한다(가능하면). 3일 이상 비었으면 질문 1개만: "오늘 떠오르는 키워드 하나만?"
2. 아니면 하나씩 묻는다.
   1. 오늘 궁금했던 것 하나? (작동 방식, 연관 개념, 왜 그런지 등 질문 형태면 좋다)
   2. 어떤 상황이었어? 한 줄만. (넘겨도 됨)
3. 대답이 짧아도 되묻지 않는다. 여기서 답이나 개념 설명을 하지 않는다.
4. 회사 고유 명칭(회사명, 도메인, 서버 IP·호스트명, 고객사, 내부 시스템명)이 나오면 `<호스트 IP>`, `<내부 시스템>` 같은 자리표시어로 바꿔 기록하고, 바꿨다고 한 줄 알린다.
5. `templates/inbox.md` 형식으로 `00-inbox/YYYY-MM-DD-키워드.md`를 만든다. `질문:`·`상황 한 줄:`에 사용자 말 그대로 적는다. `source: interview`.
   - 파일을 쓸 수 없는 환경(앱 대화)이면 같은 형식의 마크다운을 출력하고 "볼트 00-inbox에 붙여넣기"라고 안내한다.
6. 마지막 한 줄: "기록했어요. 저녁 답변 때 답이 달려요."
