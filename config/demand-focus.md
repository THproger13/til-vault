# 수요 리서치 기준

주간 수요 리서치(`demand-research`)가 이 파일을 기준으로 찾고 점수를 매긴다. 언제든 직접 고쳐도 된다.

## 관심 영역 (여기서 먼저 찾는다)
- 교육·학습: 시험 대비, 자기주도 학습, 학원·학교 운영의 반복 업무
- 개발자 생산성: 학습 기록, 블로그 습관, 문서화, 코드 구조 파악
- 습관·건강의 게임화
- 반복 계산·변환 도구: 한 번 만들면 검색으로 계속 들어오는 광고형 도구 사이트

## 내 강점 ("내 강점 연결" 점수 기준)
- Java/Spring 백엔드, PostgreSQL, Redis, Vue 2
- 교육 플랫폼(LMS) 실무 경험
- 그래프 DB로 코드·지식 구조를 분석해 본 경험
- 폐쇄망 서버 운영 경험
- Obsidian + Claude 예약 작업으로 자동화 파이프라인을 운영 중

## 시장
- 한국과 해외(영어권) 둘 다. 아이디어마다 `market: kr` 또는 `global`.

## 제외 (점수 매기기 전에 버린다)
- 오프라인 영업·현장 운영이 계속 필요한 것
- 위치정보·의료·금융처럼 인허가나 신고가 먼저 필요한 것
- 초기 사용자가 양쪽 다 있어야 돌아가는 양면 시장(매칭·중개)

## 실험 기준
- MVP는 주말 2번 안에 만들 수 있는 크기
- 실험은 2주, 성공·접는 기준을 미리 적는다
- 동시에 진행하는 실험은 1개
