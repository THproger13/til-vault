## 다음 주 글감 3개
1. [[DLQ]] — 메시지가 DLQ로 가는 4가지 경우와 "소비자 장애 대비는 DLQ가 아니라 수동 ack"라는 오개념 교정, Spring AMQP 기본값의 무한 재전달 함정. 이미 한 번 말로 복습했으니 `check` 해소(재복습 + 출처 확인)가 글 후보로 가는 첫걸음이다.
2. [[방화벽 확인 도구 ping·nc·tcpdump 차이]] — ping은 ICMP라 포트 방화벽을 못 본다, nc -zv는 TCP 포트 연결 결과, tcpdump는 SYN 도착·응답 관찰. 이번 주 새 답 노트라 말로 복습부터. 실제 장비·호스트 정보는 일반 표현으로 쓴다.
3. [[L4 포트 오픈 여부와 방화벽 상태]] — 포트 상태 3가지(열림·닫힘·필터됨)와 DROP·REJECT 구분. 2번과 묶으면 "방화벽 문제인지 서비스 문제인지 가르는 법" 한 편이 된다.
